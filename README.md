# 粮油米面价格

一行是公开页面上印出来的一个价钱。稿子没写的格子空着。36 个城市的平均价保持平均，不拆成 36 行。

`data/粮油米面.csv`

| 字段 | 说明 |
| --- | --- |
| 时间 | 稿子里的采价日或期次。正文没写出年份的行已删掉 |
| 地方 | 稿子里的省、市，或“全国”“36个大中城市” |
| 品种 | 稿子里的名字，不把“粳米(大米)”改成“粳米” |
| 规格 | 稿子里的等级 |
| 单位 | 照抄。元/500克、元/吨、元/5升不互相换算 |
| 价格 | 稿子里的本期价或成交价。环比、同比不记进这一格 |
| 原文 | 含这个价格的句子或表行 |
| 出处 | 哪一篇 |
| 链接 | 这篇的地址 |

来源有两处，都在中国价格信息网，口径不同，不要加在一起比。

各省区的大米、面粉、玉米、成品粮页面，能顺着上一篇、下一篇打开的，收了表里印出的价钱。只有图片、没有表格的，只收正文句子里写明的全国均价。

《中国市场价格监测报告》附表 1 里，36 个大中城市超市集市的月平均价，米、面、玉米粉、食用油各记一行。网站上这份月报目前从 2024 年 12 月连到 2026 年 10 月，另有 2024 年 2 月和 2022 年 1 月。每日食用油行情的城市明细要登录，公开段落里写了价的才收。
